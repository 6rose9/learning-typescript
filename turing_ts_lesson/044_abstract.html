Interface = “what something can do”
Abstract class = “what something is + shared base behavior”

Both abstract classes and interfaces are used to define contracts and structure in OOP, but they solve different problems.

Interface

An interface defines a contract.“You must implement these methods.”

  • ✅ properties
  • ✅ methods/functions
  • ❌ Access modifiers
  • ❌ Method body / implementation
  • ❌ Constructor implementation
  • ❌ object creation
  • Mostly method definitions
  • Supports multiple interfaces
  • Focuses on capability/behavior
  • Loose coupling
  • A class can implement many interfaces.

Abstract

An abstract class is a partially completed base class.

  • ✅ abstract methods
  • ✅ normal methods
  • ✅ properties
  • ✅ constructor
  • ✅ access modifiers
  • ✅ contain implementation
  • ❌ instantiate directly
  • Supports inheritance

When to use which?

Use interface when
  • defining capability
  • unrelated classes share behavior
  • you only need contract
  • multiple inheritance is needed
Use abstract class when
  • classes share code
  • you need default behavior
  • you want protected/private members
  • objects are closely related
